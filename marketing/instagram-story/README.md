# 인스타그램 스토리 홍보 컷 (1080×1920)

`node scripts/build-story.mjs` (또는 `npm run story`, dev 서버 실행 중 필요)로 다시 만들 수 있습니다.
사이트와 같은 글꼴·스타일·실제 카드 컴포넌트로 렌더링하므로, 콘텐츠 개수나 디자인이 바뀌면 다시 실행하세요.

| 순서 | 파일 | 내용 | 올릴 때 팁 |
| --- | --- | --- | --- |
| 1 | `01-hook.png` | "모이면 뭐 하지?" — 공감 유도 | 첫 컷이 넘김률을 좌우해요. 짧은 효과음/음악 스티커 추천 |
| 2 | `02-intro.png` | 로고 · 한 줄 소개 · 유형별 카드 수 | |
| 3 | `03-how.png` | 사용법 3단계 + 슬롯 | |
| 4 | `04-balance.png` | 밸런스 게임 실제 카드 | **투표 스티커**("1분 단답 vs 3시간 장문")를 카드 아래 빈 공간에 붙이면 참여가 늘어요 |
| 5 | `05-psych.png` | 심리테스트 → 즉시 결과 | **퀴즈 스티커**로 "너라면 몇 번?" 질문을 붙여도 좋아요 |
| 6 | `06-talk.png` | 대화 질문 + 꼬리 질문 | **질문 스티커**("나는 이럴 때 알아챈다")로 답변 받기 |
| 7 | `07-cta.png` | 사이트 주소 + 시작 유도 | 점선 박스 위에 **링크 스티커**(https://devlee0908.github.io/dugeun-slot/)를 붙이세요 |

- 핵심 내용은 화면 위 약 12%, 아래 약 20%를 피해 배치했어요 (프로필 바·답장 입력창에 가리지 않도록).
- 1~3컷은 스토리 하이라이트 「두근슬롯」으로 묶어 두면 프로필에서 계속 보여요.

## 함께 쓸 문구 예시

- 스토리 텍스트: `다음 모임 어색할 틈 없음 🎰💗`
- 게시물/릴스 캡션:
  > 모이면 뭐 하지? 연애 얘기 꺼내기 애매할 때 🎈
  > 폰 한 대로 돌리는 연애 수다 카드, 두근슬롯 💌
  > 밸런스 게임 · 대화 질문 · 고르면 바로 나오는 심리테스트까지
  > 가입 없이 무료! 프로필 링크에서 바로 시작 👆
- 해시태그: `#두근슬롯 #밸런스게임 #심리테스트 #연애테스트 #연애질문 #아이스브레이킹 #커플게임 #술게임대신 #MT게임 #소개팅질문`
